## Mod Management Overview

The manager downloads mods from Thunderstore, resolves dependencies, and writes them into profile folders. It runs on Windows, Linux, and macOS with the same interface. Profiles can be exported and imported as files.

Users keep a portable install on an external drive, share profiles with friends, and switch between game versions. r2modman features that come up include profile export, the mod browser, and per-profile settings.
